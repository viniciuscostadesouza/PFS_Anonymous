# Presence Factor Scale (PFS) - Supplementary Research Material

This repository contains the open supplementary materials, scoring templates, application rubrics, and validation datasets for the **Presence Factor Scale (PFS)**, an a priori engineering instrument for evaluating presence in Virtual Reality environments without human-subject trials.

## Repository Contents

- `PresenceFactorsScale-PFS.xlsx`: Automated calculation spreadsheet for scoring virtual environments across all 23 factors.
- `PFS_ApplicationGuide.pdf`: One-page operational guide detailing factor definitions and level anchors.
- `pfs_23_factors_rubric.csv`: Machine-readable rubric containing the 23 factors, categories, and calibrated score ranges.
- `benchmark1_internal_validation.csv`: Validation dataset from the controlled laboratory benchmark ($N = 123$).
- `benchmark2_external_validation.csv`: Independent multi-rater validation dataset across 17 peer-reviewed VR environments.
- `Expert_Panel_CVR_Analysis.pdf`: Psychometric content validity report and CVR consensus metrics from the expert panel.

## Usage & Anonymity Note
All materials in this repository have been anonymized for peer review in compliance with the double-blind review policy. Full attribution, project links, and software integration tools will be made available upon final publication.
